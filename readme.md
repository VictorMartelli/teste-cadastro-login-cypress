# 🔒 Testes de Cadastro e Login com Cypress

Este é um projeto focado na automação de testes End-to-End (E2E) para as funcionalidades críticas de **Cadastro** e **Login** em uma aplicação web, utilizando o framework **Cypress**.

## 🎯 Escopo do Projeto

O objetivo principal deste repositório é fornecer um conjunto de testes robustos que validem o ciclo completo de autenticação do usuário:

* **Fluxo de Cadastro (Registro):** Testar cenários de sucesso e falha (ex: campos inválidos, e-mail já registrado).
* **Fluxo de Login (Autenticação):** Testar credenciais válidas e inválidas, garantindo a correta entrada e negação de acesso.

## 🚀 Tecnologias e Dependências

| Tecnologia | Função |
| :--- | :--- |
| **Cypress** | Framework principal para testes E2E. |
| **JavaScript** | Linguagem utilizada para a escrita dos specs de teste. |
| **Node.js** | Ambiente de execução necessário para gerenciamento e execução dos testes. |
| **npm/yarn** | Gerenciadores de pacotes. |

## ⚙️ Configuração e Instalação

Para configurar e executar os testes localmente, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/VictorMartelli/teste-cadastro-login-cypress.git](https://github.com/VictorMartelli/teste-cadastro-login-cypress.git)
    ```
2.  **Navegue até o diretório:**
    ```bash
    cd teste-cadastro-login-cypress
    ```
3.  **Instale as dependências:**
    ```bash
    npm install
    # ou
    yarn install
    ```
